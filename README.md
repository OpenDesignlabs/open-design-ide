## Project Vision

I am trying to combine two open source projects: **VS Code** and **Penpot** (the open-source Figma alternative). 

The core idea is to leverage the strengths of both platforms: Penpot for its design capabilities and VS Code for its coding capabilities. By integrating them, we create an IDE that has both capabilities in one place.

### Current Progress & Status
- **Rebranding:** Successfully rebranded VS Code to Open Design IDE.
- **Integration:** Attempting to render Penpot within VS Code via an iframe (similar to VS Code's in-built browser).
